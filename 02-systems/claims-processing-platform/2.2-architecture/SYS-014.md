# Claims Processing Platform

The target platform for CAP-001. Accepts claims through the Claims
Intake API (INT-003), adjudicates against policy and coverage rules,
and disburses through the Payment Disbursement API (INT-007). Design
rationale for the integration style is recorded in ADR-001.
