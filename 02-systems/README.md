# 02 Systems

Systems level: structure and integration. One folder per system or
portfolio, each carrying the same four focus areas:

- `2.1-strategy`, `2.2-architecture`, `2.3-roadmaps`, `2.4-standards`.

A system folder is admitted by work package, following
`06-operations/runbooks/admitting-a-system.md`. The worked example is
`claims-processing-platform/`.
