# Generated Views

Every file here except this README is generated by
`python3 00-meta-model/render_views.py` from the catalog
(00-meta-model/catalog.toml) and the view register
(00-meta-model/views.toml). Each registered view appears twice: a
Mermaid source (.mmd), which is the editable and diffable form, and a
rendered SVG (.svg), which is the evidence form.

Never edit a generated file by hand. To change a drawing, change the
catalog or the register entry and regenerate. The verifier fails on
stale outputs and on files that no registered view produced.
