# Runbook: Agent Access

Agents work this repository under the contract in `AGENTS.md`: they may
propose changes as pull requests and run reconciliation, and they may
never merge. Access is granted per repository by the owning architects,
scoped to the agent's identity, and revoked by removing that identity's
access. Grants and revocations are recorded as pull requests against
this runbook, so the access history is part of the record.
